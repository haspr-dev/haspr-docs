There are many ways to contribute to haspr, and one of the most rewarding is helping translate the application into your language. Contributions are always welcome, and different tasks can be addressed depending on your profile:
- As a **translator**, you can translate strings or improve existing translations by contributing directly to the locale files in our repositories.
- As a **proofreader**, you can review and verify translation Pull Requests on GitHub.
- As a **developer**, you can identify missing translations and [externalize](/contribute/translator/externalize/) them in the source code.

## General guidelines

### Source language

haspr is developed in British English (`en-UK` / `en_UK`), which serves as the canonical source language across all components. If you discover an error in English or notice a string that is not available for translation:
- If you have a developer profile, please refer to [how to externalize strings](/contribute/translator/externalize/).
- Otherwise, please open a discussion on our [community forum](https://github.com/haspr-dev/haspr-docs/discussions).

### Tone of voice

The application voice should remain clear, respectful, and user-friendly. In languages with formal and informal forms of address (such as German "*Sie*" or French "*vous*"), the formal formulation should generally be preferred.

### Inclusion

Inclusion is a core haspr value. Translations that discriminate based on gender, ethnicity, or any personal attributes must be avoided. Neutral formulation should always be preferred when possible.

## Where translations are managed

In haspr, translations are managed **directly inside each respective repository**. You do not need third-party accounts or external tools to contribute.

### 1. Browser Extension (`haspr-browser-extension`)

- **Application strings**: [`src/all/locales/<locale>/common.json`](https://github.com/haspr-dev/haspr-browser-extension/tree/main/src/all/locales) (e.g. `de-DE`, `fr-FR`, `es-ES`, `it-IT`, `nl-NL`, `ru-RU`, etc.)
- **Extension Store / Manifest metadata**: [`src/all/_locales/<lang>/messages.json`](https://github.com/haspr-dev/haspr-browser-extension/tree/main/src/all/_locales) (e.g. `de`, `fr`, `es`, `en`, etc.)

File format: Standard JSON:
```json
{
  "Welcome to haspr!": "Willkommen bei haspr!",
  "Save changes": "Änderungen speichern"
}
```

### 2. API Backend (`haspr-api`)

- **Server, email, and wizard strings**: [`resources/locales/<locale>/default.po`](https://github.com/haspr-dev/haspr-api/tree/main/resources/locales) (e.g. `de_DE`, `fr_FR`, `es_ES`, `nl_NL`, etc.)

File format: Standard GNU gettext PO files:
```po
msgid "Welcome to haspr!"
msgstr "Willkommen bei haspr!"
```

## How to contribute translations

1. **Fork the repository**:
   - [haspr-browser-extension](https://github.com/haspr-dev/haspr-browser-extension)
   - [haspr-api](https://github.com/haspr-dev/haspr-api)
2. **Create a feature branch**:
   ```bash
   git checkout -b i18n/german-update
   ```
3. **Update or add locale files**:
   - Edit the appropriate strings in your target language.
   - If adding a new language, copy the British English template to a new directory matching your locale code.
4. **Submit a Pull Request**:
   - Push your branch to your fork and submit a PR on GitHub.
   - Maintainers and fellow native speakers will review your contribution and merge it into the codebase.
