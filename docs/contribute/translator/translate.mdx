There are many ways to contribute to pbolt, and one of the most impactful is helping translate the application into your language. Contributions are always welcome! As a translator you can add new language translations, improve existing ones, or [proofread](/contribute/translator/proofread/) translations via GitHub Pull Requests. If you are a developer, you can also help identify missing translations and [externalize](/contribute/translator/externalize/) them in the source code.

## General guidelines

### Source language

pbolt is developed in British English (`en-UK` / `en_UK`), which serves as the source language for all components. If you discover an issue in English or find a string not marked for translation:
- If you are a developer, please refer to the [how to externalize strings](/contribute/translator/externalize/) guide.
- Otherwise, please open an issue on the [community discussions](https://github.com/pbolt-dev/pbolt-docs/discussions).

### Tone of voice

The tone should remain clear, respectful, and user-friendly. In languages with formal and informal modes of address (such as German "*Sie*" vs. "*du*" or French "*vous*" vs. "*tu*"), the formal formulation should generally be preferred unless context dictates otherwise.

### Inclusion

Inclusion is a core pbolt value. Translations that discriminate based on gender, ethnicity, or background must be avoided. Use gender-neutral phrasing whenever possible in your language.

## Where translations are managed

In pbolt, translations are managed **directly inside the source code repositories**. No third-party translation platform or external account is required:

### 1. Browser Extension (`pbolt-browser-extension`)

The browser extension translations are stored in two locations:
- **Application strings**: [`src/all/locales/<locale>/common.json`](https://github.com/pbolt-dev/pbolt-browser-extension/tree/main/src/all/locales) (for example `de-DE/common.json`, `fr-FR/common.json`, `es-ES/common.json`).
- **Web Store and Manifest strings**: [`src/all/_locales/<lang>/messages.json`](https://github.com/pbolt-dev/pbolt-browser-extension/tree/main/src/all/_locales) (for example `de/messages.json`, `fr/messages.json`).

The format is standard JSON:
```json
{
  "Welcome to pbolt!": "Willkommen bei pbolt!",
  "Save changes": "Änderungen speichern"
}
```

### 2. API backend (`pbolt-api`)

Backend, email notification, and installer wizard strings are stored under:
- [`resources/locales/<locale>/default.po`](https://github.com/pbolt-dev/pbolt-api/tree/main/resources/locales) (for example `de_DE/default.po`, `fr_FR/default.po`).

These files use standard GNU gettext PO syntax:
```po
msgid "Welcome to pbolt!"
msgstr "Willkommen bei pbolt!"
```

## How to contribute a translation

Contributing a translation or fix follows the standard GitHub Pull Request workflow:

1. **Fork the repository**:
   - [pbolt-browser-extension](https://github.com/pbolt-dev/pbolt-browser-extension) for extension translations.
   - [pbolt-api](https://github.com/pbolt-dev/pbolt-api) for API and email translations.
2. **Create a branch**:
   ```bash
   git checkout -b translation/de-DE-improvements
   ```
3. **Edit or add translation files**:
   - Locate the file for your language and edit the translated strings.
   - If adding a new language, copy the English template (`en-UK/common.json` or `en_UK/default.po`) into a new directory matching your locale code (e.g. `it-IT` or `it_IT`).
4. **Commit your changes**:
   Make sure your commit message is clear, e.g. `i18n: update German translations for settings`.
5. **Open a Pull Request**:
   Submit your Pull Request on GitHub. Community reviewers and maintainers will review the translations, discuss any questions with you, and merge them directly.
