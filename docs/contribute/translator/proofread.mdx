Proofreading and reviewing translations ensures that pbolt is accurate, consistent, and welcoming across all supported languages. Because translations in pbolt are managed directly within the git repositories, proofreading happens transparently on GitHub through Pull Request reviews and discussions.

## Reviewing translations on GitHub

Any community member fluent in a language is welcome to review translations:

1. **Browse open pull requests**:
   - Check open PRs labelled with `i18n` or `translations` on [pbolt-browser-extension](https://github.com/pbolt-dev/pbolt-browser-extension/pulls) and [pbolt-api](https://github.com/pbolt-dev/pbolt-api/pulls).
2. **Review string quality**:
   - Verify that terminology is consistent across the UI.
   - Check that placeholders like `{{name}}` or `{0}` are preserved intact.
   - Ensure the tone matches the [translation guidelines](/contribute/translator/translate/#general-guidelines) (formal address, gender neutrality, clarity).
3. **Leave constructive feedback**:
   - Use GitHub inline comments to suggest improvements directly on the diff.
   - If the translation looks great, submit an approving review!

## Reporting translation bugs

If you notice a typo, an untranslated string, or an incorrect translation while using pbolt:
- Open a GitHub issue on the relevant repository ([pbolt-browser-extension](https://github.com/pbolt-dev/pbolt-browser-extension/issues) or [pbolt-api](https://github.com/pbolt-dev/pbolt-api/issues)).
- Even better, submit a Pull Request directly with the fix!
