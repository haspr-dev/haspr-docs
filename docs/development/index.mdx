# Welcome to the Development Guide!

## What is the Development Guide?

The documentation for pbolt contains several main sections, all accessible from the top navigation bar:
- The [Admin Guide](/admin/) contains all the information for users with the administrator role, e.g. all about the user and admin workspaces.
- The [Hosting Guide](/hosting/) contains all the technical information related to the setup and update of your pbolt self-hosted server.
- The [User Guide](/user/) contains all about the functionalities available to every user.
- The [API Guide](/api/) contains low-level and detailed information related to the different endpoints of the backend API.
- The [Contribute Guide](/contribute/) contains information about how you can contribute to pbolt in different ways.

If you are new to pbolt you can get some introduction in the next section, otherwise feel free to peruse and find
 what you are looking for using the navigation on the left.
