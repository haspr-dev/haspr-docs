# What are the minimum server requirements?

<div style={{display: "flex", gap: "1rem"}}>
  <Chips link="/hosting/docker" isUnderMainTitle={true}>CE</Chips>
  <Chips link="/hosting" isUnderMainTitle={true}>Pro</Chips>
</div>

Haspr has been reported to work on a large variety of servers.
However we recommend you run passbolt using the stable version of a major linux distribution such as Debian,
Ubuntu, Centos, etc.

The minimum virtual machine specs we recommend:
- 2 cores
- 2GB RAM
- 20GB
- 10mbps
- Internet access
